# 구현 구조

## 영상 입력과 카메라 모델

카메라 스레드에서 최신 프레임과 캡처 시각을 저장합니다. 영상 크기에 맞춰 내부 행렬을 적용하고 fisheye 모델은 코너 보정 후 PnP를 계산합니다. 추정 결과는 원래 카메라 모델로 재투영해 확인합니다.

## 마커 관측

Diamond마다 ID 조합·노드 번호·코너를 함께 저장합니다. 다음 노드가 보이면 해당 Diamond를 우선 사용하고 그 외에는 영상 중심과 가까운 Diamond를 선택합니다. 중심 오차와 Yaw를 제어 관측값으로 사용합니다.

## 경로와 제어

4×4 격자의 BFS로 경로를 계산합니다. 중심 보정·회전 보정·안정화·다음 노드 이동·목적지 정지를 상태로 구분합니다. PID 출력은 X·Y 이동 속도와 회전 명령에 연결합니다.

## 장비 연결

Hiwonder 메카넘 SDK가 네 모터 명령을 계산합니다. src/hardware.py는 확장보드 주소 0x7A로 I²C 명령을 전달합니다. 모터 극성·출력 범위와 서보 펄스 형식은 Hiwonder 확장보드 프로토콜을 사용합니다.

## 기록과 검증

관측 좌표·Yaw·재투영 오차·처리 시간·주행 상태·모터 명령을 CSV로 저장합니다. 합성 마커 검출·위치 추정·BFS·주행 상태·목적지 정지·SDK와 I²C 명령 연결을 포함한 테스트 13개가 통과했습니다.
